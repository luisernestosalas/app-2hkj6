# CRM - Sistema de Gestión de Clientes y Notas

Una aplicación web simple y eficiente para gestionar clientes y sus notas asociadas, desarrollada con tecnologías web estándar.

## 🚀 Demo en Vivo

Visita la aplicación: [https://app-2hkj6-qcjpy9b86-luisernestosalas-2775s-projects.vercel.app](https://app-2hkj6-qcjpy9b86-luisernestosalas-2775s-projects.vercel.app)

## 📋 Características

- **Gestión de Clientes**: Crear, editar, visualizar y eliminar clientes
- **Sistema de Notas**: Agregar y gestionar notas para cada cliente
- **Interfaz Intuitiva**: Diseño limpio y fácil de usar
- **Almacenamiento Local**: Los datos se guardan en el navegador del usuario
- **Responsive**: Adaptable a diferentes tamaños de pantalla

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura de la aplicación
- **JavaScript (ES6+)**: Lógica de negocio
