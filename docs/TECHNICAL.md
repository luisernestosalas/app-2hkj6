## Funcionalidades Principales

### Gestión de Clientes
- **Crear cliente:** Formulario para agregar nuevos clientes
- **Listar clientes:** Vista de todos los clientes registrados
- **Editar cliente:** Modificación de datos existentes
- **Eliminar cliente:** Borrado de registros de clientes

### Gestión de Notas
- **Crear notas:** Asociadas a clientes específicos
- **Visualizar notas:** Listado de notas por cliente
